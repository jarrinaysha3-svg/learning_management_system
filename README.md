# Learning Management System (LMS)

A full-stack learning management system built with Django. Instructors create courses and lessons, students enroll and track their progress, and admins approve content before it goes live.

## Features

- User registration, login, and logout
- Course and lesson management for instructors
- Student enrollment in courses
- Progress tracking across lessons
- Quizzes attached to courses
- Instructor dashboard
- Admin approval workflow

## Tech Stack

- Python, Django
- HTML, CSS, Bootstrap 5
- Django Crispy Forms (Bootstrap 5 template pack)
- SQLite


## Usage

1. Register an instructor account and a student account.
2. As the instructor, create a course with lessons and a quiz.
3. As the admin, approve the course.
4. As the student, enroll in the course, complete lessons, and take the quiz and keep up with their progress.
